# Jayanth & Shivani — Digital Wedding Invitation

Premium React/Vite wedding invitation for 27 August 2026.

## Included
- Opening invitation animation with music
- Hero countdown and highlighted exploration CTA
- Sticky mobile-friendly navigation
- Bride-side and groom-side wedding cards with TAP TO OPEN interaction
- Event detail modals and map directions
- Dedicated engagement gallery at `/engagement-gallery.html`
- Full-screen engagement photo viewer
- Our Story timeline
- Venue map
- Share Invitation / WhatsApp / Google Calendar actions
- Send Your Blessings WhatsApp action
- Floating music play/pause and mute controls
- Wedding-day countdown state

## Gallery photos
Replace these files with your final engagement photos when ready:
- `public/our-story-1.jpg`
- `public/our-story-2.jpg`
- `public/our-story-3.jpg`

The gallery page references those files, so no code changes are required when replacing them.
