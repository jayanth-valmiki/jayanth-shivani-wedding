## 💌 Wedding Card Experience

The physical wedding invitation cards are intentionally hidden.

Guests first see an elegant digital card and:

**TAP TO OPEN FULL CARD →**

After tapping, the complete original wedding card is revealed.

Both:

* Bride's Invitation
* Groom's Invitation

follow the same interaction.

---

## 🪙 Scratch-to-Reveal Events

The Haldi, Wedding and Reception sections include an interactive scratch experience.

Guests will see:

> ✨ SCRATCH HERE

They can scratch using:

* 🖱️ Mouse
* 👆 Finger/touch

Once enough of the card is scratched, the complete event details are revealed.

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview production build

```bash
npm run preview
```

---

## ✏️ Customization

Most invitation content can be customized from:

```text
src/data.ts
```

You can update:

* Names
* Dates
* Event timings
* Venues
* Descriptions
* Gallery information
* Social/share information
* Repository URL

---

## 🖼️ Wedding Card Images
